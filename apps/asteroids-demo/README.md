# Asteroids Flight

An Asteroids-style spacecraft flight demo using One More Glow. From the
repository root, run `npm run dev:asteroids` and open the local address printed
by Vite.

Steer with Left/Right, A/D, a gamepad stick or D-pad. Thrust with Up, W, the
gamepad stick up, D-pad up or the gamepad's first face button.

See [SPEC.md](SPEC.md) for the current flight behavior.
