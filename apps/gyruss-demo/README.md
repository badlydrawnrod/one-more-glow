# Orbital Assault

A Gyruss-style orbital shooter demonstrating One More Glow. From the repository
root, run `npm run dev:gyruss` and open the local address printed by Vite.

Move around the rim with Left/Right, A/D, a gamepad stick or D-pad. Fire inward
with Space, Up, Z or the gamepad's first face button. After game over, press R
or select Restart.

See [SPEC.md](SPEC.md) for the current gameplay baseline and experimental work.
