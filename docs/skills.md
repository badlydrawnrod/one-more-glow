# Repository skills

These skills are reusable workflows for contributors and coding agents. Open
the linked `SKILL.md` for the full instructions.

| Skill | Use it to |
| --- | --- |
| [api-review](../.agents/skills/api-review/SKILL.md) | Review an API for clarity, usability, misuse resistance and compatibility. |
| [architect-review](../.agents/skills/architect-review/SKILL.md) | Check a change against established component boundaries and any explicitly agreed architectural change. |
| [grug-review](../.agents/skills/grug-review/SKILL.md) | Find unnecessary complexity and maintainability risks. |
| [mechanical-enforcement](../.agents/skills/mechanical-enforcement/SKILL.md) | Protect an agreed, repeatable property with a proportionate automated check. |
| [skeptic-review](../.agents/skills/skeptic-review/SKILL.md) | Resolve ambiguity before substantial planning and challenge the evidence for an outcome. |
