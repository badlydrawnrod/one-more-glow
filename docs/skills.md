# Repository skills

These skills are reusable workflows for contributors and coding agents. Open
the linked `SKILL.md` for the full instructions.

| Skill | Use it to |
| --- | --- |
| [api-review](../.agents/skills/api-review/SKILL.md) | Review an API for clarity, usability, misuse resistance and compatibility. |
| [architect-review](../.agents/skills/architect-review/SKILL.md) | Check a change against the documented architecture and component boundaries. |
| [grug-review](../.agents/skills/grug-review/SKILL.md) | Find unnecessary complexity and maintainability risks. |
| [mechanical-enforcement](../.agents/skills/mechanical-enforcement/SKILL.md) | Turn a validated rule or recurring defect into a proportionate automated check. |
| [skeptic-review](../.agents/skills/skeptic-review/SKILL.md) | Challenge assumptions and look for evidence-based correctness gaps. |
